# Buildy Website & App Builder

Create websites, web apps, online stores and sales funnels from a conversation. Connect your Buildy account, choose a project, ask for changes, inspect its preview and publish when ready. Read earlier project messages to continue work.

The connector sends requests to the normal Buildy agent. Actions use your existing permissions, setup, billing and confirmations. Some features require a plan, purchased resources, usage allowance or external advertising spend. Availability also depends on the host's policies. There is no separate free allowance in this package.

## Connect and use

1. Connect the Buildy connector and sign in or create a Buildy account.
2. Review the requested access and approve or cancel it.
3. Ask to list your projects, start a new one, or continue an existing project.
4. Ask to open the preview. Buildy prepares its runtime when needed. A preview can sleep when idle.
5. Ask to publish when ready. Wait for the publication result and open the returned live site. Creating or editing alone does not publish.
6. To connect an existing domain, open the project in Buildy and go to Dashboard > Domains and Email.
7. Disconnect from the host or revoke access in Buildy when finished.

Requests to create or change a project consume the account's normal allowance. Waking a preview can use runtime resources but does not send an AI edit message. Status reads do not keep a sandbox awake. Host rendering and browsing support vary; a returned preview link does not guarantee the assistant can inspect it.

## Privacy

Buildy receives the tool arguments needed for your request. History retrieval shares selected user-facing Buildy messages with the connected AI host. It does not request the host's full conversation history. Read the privacy policy for storage, providers and retention. Do not put secrets in prompts or public previews. Revoking access blocks later connector requests; it does not undo actions already completed or remove data already received by the host.
